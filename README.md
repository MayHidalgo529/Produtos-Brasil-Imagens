# Produtos Brasil — imagens públicas

Repositório público destinado exclusivamente às fotos dos produtos do catálogo Produtos Brasil.

Os links públicos dos arquivos serão registrados nas colunas de imagens da planilha oficial; o site consome a planilha automaticamente.

Padrão de pastas: `produtos/pNNN/nome-do-produto.jpg`.

Não adicionar custos, margens, dados de pagamento ou outros dados internos.
